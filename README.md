# Інформаційно-довідкова система поліклініки

Навчальний проєкт (лабораторна робота №1). Статична сторінка: відділення, лікарі з пошуком, контакти.

**Стек:** HTML5, CSS3, JavaScript; локальний сервер на Ruby (WEBrick).
У наступних роботах: React, Ruby REST API, PostgreSQL.

## Запуск локально

```bash
gem install webrick
ruby server.rb
```

Відкрити http://localhost:8000

(Альтернатива: розширення Live Server у VS Code.)

## Публікація

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
